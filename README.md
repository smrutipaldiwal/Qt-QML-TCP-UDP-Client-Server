# Qt/QML TCP/UDP Client-Server Application

A client-server application developed using C++, Qt and QML,
supporting TCP/UDP socket communication and record management.

## Technologies

- C++
- Qt
- Qt Quick / QML
- TCP/IP
- UDP
- Sockets
- CMake
- Multithreading
- Ubuntu
- Qt Creator

## Project Structure

client/
    QML-based client application

server/
    C++ server application

## Features

- TCP/UDP communication
- Client-server architecture
- Add records
- Update records
- Delete records
- Server acknowledgements
- QML-based graphical interface
- Socket communication
- Multithreaded server handling

## Architecture

Client (Qt/QML)
       |
       | TCP / UDP
       ↓
C++ Server
       |
       ↓
Record Management
